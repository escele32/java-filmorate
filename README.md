# java-filmorate
Template repository for Filmorate project.

![схема базы данных для пректа](src/main/database_schema/schema_db.png)

Комментарии помечаю как 
Вкусовщина - на твое усмотрение
Желательно - желательно поправить
Обязательно - обязательно обрати внимание

Комментарии по схеме: 
1) назови таблицу genre как genres чтобы было в едином стиле (Вкусовщина)
2) (обязательно) у тебя получается что у одного фильма может быть только 1 жанр. По условиям их может быть несколько
3) (желательно) укажи типы данных в схеме
4) (желательно) опечатка в таблице friends поле status_id
5) (обязательно) сущность status кажется лишней. Подразумевается (пока) 2 статуса подтвержденная / неподтвежденная , делать сущность избыточно ради этого
6) (желательно) укажи в правильном стиле связи между таблицами (см например https://practicum.yandex.ru/blog/chto-takoe-er-diagramma/)
7) (желательно)  поле id в сущности friends кажется избыточным. особенно если сделать составной ключ (user_id + friend_id) - эта пара должна быть уникальна, аналогично с лайками
8) (обязательно) у тебя запросы написаны неправильно. например
SELECT
      films.name,
      genre.name AS genre_name,
      mpa.name AS mpa_name,
      films.release_date,
      films.duration
    FROM films
    JOIN genre ON films.FK_genre_id = genre.id
    JOIN mpa ON films.FK_mpa_id = mpa.id;
   такого поля "FK_mpa_id" - нет , есть только mpa_id. (FK - foreign key - указывается в схеме только)
